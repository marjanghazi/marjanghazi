## ⚛️ Quantum Computing Journey

I maintain a dedicated repository documenting my hands-on progression in quantum computing:

### 📚 **Quantum Learning**
🔗 **Repository:** [github.com/marjanghazi/Quantum-learning](https://github.com/marjanghazi/Quantum-learning)

The repository documents my practical learning journey from fundamental quantum concepts toward quantum algorithms, simulation, optimization, and emerging quantum architectures.

Current implementations include:

- 🪙 **Quantum Coin Flipper**
  - Built from scratch using Python
  - Demonstrates superposition and probabilistic quantum measurement concepts

- 🚀 **Quantum Teleportation**
  - Implemented using **Qiskit**
  - Explores entanglement, Bell states, classical communication, and state reconstruction

- 🔍 **Grover's Search Algorithm**
  - Implementation of quantum amplitude amplification
  - Demonstrates quantum search advantages for unstructured search problems

- ⚛️ **Variational Quantum Eigensolver (VQE)**
  - Small hybrid quantum-classical implementation
  - Exploring variational circuits and optimization

- ⚛️ **Neutral-Atom / Rydberg Quantum Computing — In Progress**
  - Exploring neutral-atom quantum architectures
  - Building and simulating two-atom analog registers
  - Studying pulse programs, Rydberg interactions, and analog quantum evolution

The goal of this repository is not only to implement algorithms, but also to **understand the underlying mathematics, physical concepts, circuit behavior, and computational implications**.

## 🔐 Final Year Project / Research Project

### **QuantX — Post-Quantum Secure Communication Platform**

**QuantX** is my Final Year Project focused on building a practical **quantum-safe communication architecture** capable of protecting sensitive communication against both classical and future quantum-enabled attacks.

The system explores the integration of:

- 🔑 **ML-KEM (Kyber)** — Post-quantum key encapsulation
- ✍️ **ML-DSA (Dilithium)** — Post-quantum digital signatures
- 🔒 **AES-256-GCM** — Authenticated symmetric encryption
- ⚡ **FastAPI** — Backend API architecture
- ⚛️ **React** — Frontend application
- 🗄️ **PostgreSQL** — Data persistence

The project allows me to explore how **NIST-standardized post-quantum cryptographic algorithms can be integrated into real-world software systems** rather than studied only theoretically.

My broader research interest is in understanding how **quantum-resistant cryptography and future quantum communication technologies can coexist within secure communication infrastructures**.
